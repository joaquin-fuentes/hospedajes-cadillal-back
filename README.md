# Hospedajes Cadillal - Backend

## Descripción del proyecto

Este es el backend del proyecto **Hospedajes Cadillal**, una API RESTful creada para gestionar información de hospedajes en la región del Cadillal.

---

## Tecnologías usadas

- **Node.js** - Entorno de ejecución.
- **Express.js** - Framework para crear el servidor web.
- **MongoDB** - Base de datos NoSQL para almacenar la información.

---

## Instalación básica

1. Clona el repositorio:
   ```bash
   git clone https://github.com/joaquin-fuentes/hospedajes-cadillal-back.git
   ```
2. Ingresa el siguiente comando en la terminal: npm install
3. Inicia el servidor: npm run dev
